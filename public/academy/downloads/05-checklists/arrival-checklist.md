## Before Entering

- [ ] Parked legally and respectfully (not blocking driveway or mailbox)
- [ ] Arrived within agreed service window
- [ ] Texted or called client if running more than 10 minutes late
- [ ] Reviewed job notes, access code, and special instructions
- [ ] Uniform presentable; supplies ready to unload efficiently

## Entry & First Impressions

- [ ] Greeted client professionally (if home) or followed silent-entry protocol
- [ ] Shoe covers on OR indoor shoes per client preference
- [ ] Confirmed scope of work matches booking (rooms, add-ons, exclusions)
- [ ] Asked about any changes since last visit or new areas of concern
- [ ] Confirmed pet status and safety (crated, friendly, areas to avoid)
- [ ] Confirmed product sensitivities or "no scent" requests

## Home Walkthrough & Setup

- [ ] Quick walkthrough of home to identify priority areas
- [ ] Noted any pre-existing damage or concerns (photo if needed)
- [ ] Confirmed which rooms are in scope and which are off-limits
- [ ] Located electrical outlets, water source, and trash disposal
- [ ] Supplies staged in one area — not spread across the home
- [ ] "Cleaning in progress" sign placed if company provides one

## Documentation — Before Photos

- [ ] Before photos taken per company SOP (see Photo Checklist)
- [ ] Clock in / job started logged in app
- [ ] Any access issues or scope changes reported to manager immediately

## Ready to Clean

- [ ] Work plan set — start with driest rooms, finish with wettest (baths/kitchen)
- [ ] Music/phone on silent; personal calls only on break
- [ ] Client belongings respected — nothing moved without permission
